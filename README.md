# Ebook Auto Reader

DMMブックスで購入済みの日本語書籍を、Androidで自然に耳から読めるようにする個人向けプロジェクトです。縦書きのリフロー型書籍を優先し、原文を保全しながら漢字や固有名詞の誤読を減らします。

現在は開発初期です。正式方針は [製品仕様](docs/product-spec.md)、責務と同期方式は [アーキテクチャ](docs/architecture.md) を参照してください。

- [ロードマップ](docs/roadmap.md)
- [技術選定と評価方法](docs/research-plan.md)
- [実機から得られた知見](docs/validated-findings.md)

公開リポジトリでは自作の試験素材を使用します。購入済み書籍に対する検証は、本人の端末上で、OS・サービスが許可する操作の範囲で行います。

- [P1 選定と測定結果](docs/p1-results.md)
