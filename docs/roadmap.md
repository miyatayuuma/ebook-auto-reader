# ロードマップ

| 工程 | 内容 |
| --- | --- |
| P0 | 正式設計と開発判断の登録 |
| P1 | OCR・TTS・読み補正の実測比較、技術試作、ページ連結と同期方式 |
| P2 | Android中核エンジン。許可された画面取得、縦書き本文、読み補正、文の連結、先読み、合成と再生の一連の動作 |
| P3 | 図表・章扉・白紙、巻末、同期と安全復帰、操作性 |
| P4 | ポケット運用、読書記録、メモ |
| P5 | 長時間実機試験、性能改善、正式リリース |

P2は、同じ自作原文での実機OCR比較と試聴を踏まえて開始する。表示移動・画面取得の可否を最初に測り、認識不能時の安全停止と、前後2ページの読みと表示復元を優先する。図表の詳細読み、ポケット操作、読書支援は各後続工程の受入条件で扱う。
