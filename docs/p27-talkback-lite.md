# P2.7 lightweight TalkBack companion — implementation and acceptance

Separate package io.github.ebookautoreader.lite, separate Gradle project p27/lite. Existing OCR APK and acquired private data are untouched. The approved product split supersedes OCR/TTS and silence restrictions only for this companion; old engine and research are preserved. No OCR, text retrieval, audio recording, custom TTS, network, models, persistent page content or protected API bypass.

## Defaults and behavior
- TalkBack ON in DMM PublusReaderActivity starts; OFF stops. Enable service before opening DMM; book activity event is required, no bookPageView ID gate.
- AudioPlaybackCallback usage ACCESSIBILITY, content UNKNOWN or SPEECH. Snapshot verifies before input. Candidate is not proof of speech identity or completed page. Default stopped interval 800 ms (configurable 500–4000), no-speech wait 1500 ms (1000–8000). Initial startup guard uses the configured no-speech wait. No claim that these intervals are validated across books/speeds.
- Two-finger horizontal swipe, 120 ms, default rightward (left to right); direction explicitly selectable. Coordinate tap retired following device failures. No automatic retries. Verify two stable changed window signatures. Manual page change rebinds the stable page signature and resets speech state rather than terminating the session; detect via DMM content events and pre-turn signature check. Stop if unstable, no progress, screen lock, other app, menu, gesture failure. Notification shade holds input; conservative stop on return, rearm via TalkBack OFF/ON. Emergency stop via notification, tile or settings; latch until TalkBack OFF.
- After a page transition, a speech burst shorter than 1200 ms is not sufficient evidence of body read completion. Longer announcements can still be misclassified; a short isolated burst uses the no-speech wait instead of the read-end wait. 800 ms silence after qualified speech is unchanged.
- Page-turn timing is determined exclusively by TalkBack enabled state and the observed speech playback state: 800 ms of silence after qualified speech or 1500 ms without qualified speech. This includes the initial page and successive silent pages; no content classifier, image gate, image-specific waiting, or count limit. The page signature is solely for transition verification and manual synchronization, using official takeScreenshotOfWindow and in-memory downsampling, without persistent pixels. Delayed speech can lead to an unintended skip; indistinguishable successive page signatures can still cause a safe stop.
- SCREEN_DIM_WAKE_LOCK while active, bounded/renewed, releases on stop. This is not guaranteed minimum brightness, no global brightness change. USB-independent/face-down acceptance pending. Disable proximity stop in TalkBack; keep speech display and hide-screen features off for first test.
- Daily flow: prepare DMM with TalkBack OFF, turn ON; OFF to end. Enable notifications for emergency stop, optional QS tile.
 
## Install and test
Download CI artifact p27-talkback-lite with gh, adb install -r app-debug.apk, launch io.github.ebookautoreader.lite/.SetupActivity. Disable old Reader and Probe accessibility services (do not uninstall or clear), enable Ebook Auto Turn service and notifications. Open DMM, set font/margins/position, enable TalkBack. adb logcat -v threadtime -s EbookAutoTurn:I. Observe normal pages, short/long body, initial and consecutive silent pages (including figures and blanks), delayed speech, no incorrect skip, manual page change, menu/shade/lock, TalkBack OFF, stop notification, USB-disconnected face-down >10 minutes. If no start after service enabled inside DMM, reopen reader to emit activity state event. If swipe direction is wrong, toggle the explicit rightward-swipe setting and rearm. Verify fast swipe, manual forward/back, and short operation announcements. Test 100 pages / 120 min before final acceptance. Do not publish raw logs/private page content. No claim of final device acceptance before actual results.
