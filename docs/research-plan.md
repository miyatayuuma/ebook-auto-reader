# 技術選定と評価方法

- OCRはNDLOCR-Liteの最新正式版とML Kit日本語を比較する。端末解像度の自作縦書き画像を、小・中・大の文字サイズで生成する。原文の文字誤り・脱落・挿入・順序、本文・ルビ・キャプション・章扉・ページ番号の対応、モデルとライセンス、速度・PSSを記録する。NDLはCPUで、前後処理・読み順まで評価する。
- TTSはGoogle TTSを基準に、正解テキストと同じ文に読みを付けた入力を試聴する。多音語・固有名詞・数字・単位・専門語・長文・指定読みを扱い、誤読と自然さを個別に判定する。ローカル候補はAndroid運用、合成速度、連続再生、ライセンスを比較する。クラウドは公式API・無料枠・入力データの扱いを確認する。
- 読み推定は組版ルビ、辞書、形態素解析を対象に、同じTTSと同じ文の前後を比較する。読み推定の一致率と音声の誤読率は別に記録する。
- PC、Androidビルド、Pixel実機、本人試聴を別々に記録する。試作は本体実装と独立させ、実機で有力候補を選ぶまでに必要な操作を一回にまとめる。
