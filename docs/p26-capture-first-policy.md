# P2.6 capture-first reading policy — 2026-11-28

User decisions: the shared acquisition engine operates whenever the enabled reader is showing the default numbered/title layout. Ordinary manual reading never triggers page gestures; passive capture runs independently. EARS uses parallel acquisition, OCR/cache, synthesis and playback, reusing verified stored pages. TalkBack ON enables the automatic page-turn controller when explicitly enabled; previous user-reported on-device silence-triggered turning and next-page reading worked. OCR runs independently; do not gate normal TalkBack speech on OCR. Confirmed figure-only pages may be advanced without speech; unknown/mixed pages must not be silently skipped. Only one turn owner and one speech engine at a time.

J1 first: observe actual manual forward/back/jump events on Pixel with TalkBack on/off; accessibility events are hints, screenshot signatures are fallback, number OCR on stable changed pages even when body cached. Detect menus, overlays, screen lock, other apps, book/layout changes; stop observation outside authorized reader. Measure detection delay, false positives, CPU/memory/battery; no claim that DMM emits every event. J2: bounded passive OCR queue, immutable captured frame with identity, no reader blocking or gestures. Keep missed pages unacquired; record unresolved separately. D2: local book/layout/page index, exact-image evidence, migrate existing trial journal/cache without re-OCR; distinguish scanned/saved/unresolved. K: recover prior silence control, arm after speech start, account for transient pauses, revalidate stable destination and prevent duplicate turns; unknown silent page fail closed. A1b/A2: PCM/AudioTrack; B2: saved-first EARS; G: cross-page sentence assembly, original fidelity. F2 remains independent debug acquisition/repair route; no change to installed APK or PR16 checkpoint.

The existing product spec and AGENTS.md describe OCR-only and TalkBack comparison. This decision record requests the scoped EYES change; update normative sections at integration after J1/K acceptance. Existing safeguards remain: official APIs, no DRM bypass, no external text transmission, no assumed permanent full-book archive; debug cache only until retention/permission is decided. User consent and disable controls; no hidden screen capture outside DMM. No actual book data, title, screenshots or logs in repository.

Parallel Web Ebook Reader W0: private browser-extensions repository, independent MV3 extension. Shared conceptual contract: book/layout/page identity, source lines/ruby/bounds/roles BODY/HEADING_CANDIDATE/CAPTION/FIGURE_TEXT/UNKNOWN, page kinds BODY/HEADING/FIGURE/BLANK, recognition status, verified storage before advancing, stop on identity/storage faults; no cross-platform data transfer until permissions and mapping are approved. Browser-specific DOM detection and speech events first, visible-screen OCR only if allowed and necessary. Validate foreground/background/lock before calling it an audiobook replacement.
