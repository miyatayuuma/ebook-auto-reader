# P2.7A-0 — observation only
Separate package io.github.ebookautoreader.talkbackprobe; no update to installed OCR reader or cache. Official AudioManager callback and snapshots, accessibility windows/events. No audio recording, TTS, OCR, screenshot, gesture, wake lock, settings modification, network or content persistence. Synthetic fixture only for overlay event/node lengths and exact known synthetic phrase matches; DMM mode measures audio attributes only. No DMM text inspection. A zero match is not proof an overlay cannot ever be accessed; nonzero length alone is not proof speech output is visible. Audio usage/content are anonymized candidates, not source identity or acoustic silence. 200 ms polling during explicit armed scope for diagnostic comparison only; production event-driven target. 10-minute automatic expiration; foreground and TalkBack checks; stop via fixture or disable service.
 
Install artifact independently: gh run download RUN --repo miyatayuuma/ebook-auto-reader --name p27-talkback-probe --dir /tmp/p27-probe; adb install -r /tmp/p27-probe/app-debug.apk. Launch TalkBack Probe, enable its service in accessibility settings, leave existing OCR app disabled/stopped for test (do not clear data). Start adb logcat -v threadtime -s TalkBackProbe:I. With TalkBack speech output display ON, arm fixture, focus both synthetic labels, listen, wait 4 seconds between, switch display OFF and repeat as control. Record fixtureMatches, chars, candidate_on/off, gap candidates. Then turn TalkBack off, arm DMM audio mode, open a chosen numbered or unnumbered text page, enable TalkBack, manually advance after each page ends, observe 3 pages and a figure, turn off. DMM mode does not read overlay nodes/events. End probe or disable service. No page-end threshold is accepted before labeled results. Screen keep-awake/face-down behavior will be separately validated during implementation; proximity stop disabled in TalkBack settings if desired. Desired product trigger: TalkBack ON in DMM starts, OFF stops; explicit emergency stop suppresses rearm until OFF, no OCR runtime.
